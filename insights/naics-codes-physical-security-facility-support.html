NAICS codes for physical security and facility support services, explained

NAICS codes decide which solicitations you see, which size standard you are measured against, and how a contracting officer classifies what you do. For security and facility work the codes are easy to mix up. Here is what the relevant ones mean and how to choose.

Apex Gama Defense Solutions · 8 min read

The North American Industry Classification System (NAICS) is how the federal government categorizes what a business does. For a contractor it matters for three concrete reasons: a contracting officer assigns a NAICS code to each solicitation, your business is measured against the Small Business Administration size standard tied to that code, and the primary code you select in SAM.gov signals your core line of business. Pick carelessly and you either miss opportunities or get measured against a size standard that works against you. For security and facility services, several codes sit close together and are routinely confused.

Primary vs. additional codes

In your SAM.gov registration you choose one primary NAICS code — your principal line of business — and as many additional codes as genuinely apply. The primary code is what most directory searches and small-business profiles key on, so it should reflect what you actually do most. The additional codes broaden the solicitations you are eligible to be considered for. You do not get to pick the code on a given solicitation; the contracting officer does, based on the principal purpose of the requirement. Your job is to be registered under the codes a reasonable CO would use for the work you can perform.

The security and facility codes that matter

These are the codes most relevant to physical security, training, advisory, and facility-operations work, with their official titles:

  • 561210 — Facilities Support Services. Operating and supporting a client's facility: combining services such as operations, maintenance coordination, and related support under one provider. The code for an operational-management and facility-readiness line of business.
  • 561612 — Security Guards and Patrol Services. Guard-force and patrol operations. A licensed, labor-intensive service — distinct from assessing or designing a security program.
  • 561613 — Armored Car Services. Secured transport of valuables.
  • 561621 — Security Systems Services (except Locksmiths). Selling, installing, monitoring, and maintaining security systems — alarms, access control, CCTV.
  • 561622 — Locksmiths. Lock and key services.
  • 541690 — Other Scientific and Technical Consulting Services. Advisory and consulting work, including security and risk consulting — the code for assessment, program design, and advisory.
  • 541330 — Engineering Services. Where security work is engineering-driven (e.g., physical-security engineering).
  • 611430 — Professional and Management Development Training. Training programs for working professionals.
  • 611519 — Other Technical and Trade Schools. Specialized technical and tactical instruction.
  • 561990 — All Other Support Services. A catch-all for support services not classified elsewhere.

The distinction that trips people up

The most common confusion is treating “security” as one code. It is not. Guarding (561612), installing systems (561621), and assessing and designing a program (541690) are three different lines of business with three different size standards and three different buyer expectations. A firm that assesses and advises should not primarily classify itself as a guard company, and a contracting officer who sets 561612 is buying guards, not consulting. Be honest about which one describes your core work, and register additional codes for the adjacent ones you can genuinely perform or team for.

Size standards: why the code changes your status

Every NAICS code carries an SBA size standard — either an annual-receipts threshold or an employee count — that determines whether your business counts as “small” for a given procurement. The thresholds differ by code, and the SBA updates them periodically, so the same company can be small under one code and not under another. This is a real strategic consideration: the code a solicitation carries sets the field you compete in. Always confirm the current size standard for a code against the SBA's size-standards table rather than relying on a figure you remember.

How to choose your primary code

  • Name what you do most in plain terms, then find the code whose official definition matches it — not the one that sounds most impressive.
  • Prefer the code whose size standard reflects your line of business honestly; do not reverse-engineer a code to game a threshold.
  • Add the adjacent codes you can perform or team for, so you appear in the right searches and are eligible to be considered.
  • Keep your capability statement and SAM profile consistent with the codes, so an evaluator sees one story.

A note on accuracy

NAICS codes are revised on a multi-year cycle and SBA size standards change more often than that. Treat any specific code or threshold — including the ones above — as a starting point to verify against the current NAICS manual and the SBA size-standards table before you rely on it in a registration or a bid.
