# Apex Gama Defense Solutions — Brand Kit

Everything you need to use the brand outside the website — in capability
statements, proposals, PowerPoint, Word, business cards, letterhead, and social
media. Open **`brand-guide.html`** in a browser for the visual guide (and print it
to PDF if you want a shareable brand book).

## How to download this kit
- **Whole repo:** on GitHub → green **Code** button → **Download ZIP**. The kit is
  the `brand/` folder.
- **Just the brand folder / one file:** open any file on GitHub and use the
  **Download raw file** button.

## Files

**`logo-svg/`** — vector, infinitely scalable. Use these wherever possible (web,
print, large formats). Transparent background.
- `logo-horizontal.svg` — default lockup (headers, letterhead)
- `logo-primary.svg` / `logo-stacked.svg` — stacked lockups (covers, social)
- `logo-white.svg` — reversed, for dark backgrounds **only**
- `logo-mono.svg` — single-color, for one-color print / engraving
- `icon-mark.svg` — the mark alone (avatar, favicon source)
- `favicon.svg`, `og-cover.svg` — web favicon and social share image

**`logo-png/`** — raster with transparent background, for software that can't
place SVG (PowerPoint, Word, some print/social tools). High-resolution.
- `logo-horizontal.png`, `logo-white.png`, `logo-mono.png`
- `logo-primary.png`, `logo-stacked.png`, `icon-mark.png`
- `favicon-512.png`, `social-cover.png`

## Fonts (free — Google Fonts)

- **Source Serif 4** — headings / display
- **IBM Plex Sans** — body & UI
- **IBM Plex Mono** — labels, codes, data

Install free from fonts.google.com, or in Google Docs/Slides they're available
under "More fonts." For Microsoft Office, download and install the font files.

## Rules of thumb

- Public brand everywhere: **Apex Gama Defense Solutions**. Never present "DBA" publicly.
- Legal entity only where legally required: **Apex Gama Defense Solutions LLC**.
- "Gama" is intentional — never "Gamma."
- Keep ochre as an accent; don't fill large areas with it.
- Use the white logo on dark backgrounds, the dark logo on light — never dark-on-dark.
